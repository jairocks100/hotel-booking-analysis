# Local data setup

Copy your original assessment workbook to `data/hotel_bookings.xlsx` before running `python code/analysis.py` from the repository root.

The assessment PDF is optional reference material and is not read by the Python scripts. Neither original input is committed to this source-only repository. `hotel_bookings.xlsx` must be the supplied 12,000-row, 28-column workbook; the analysis intentionally checks this contract.

Keep all input files local. The root `.gitignore` excludes every file under `data/` except this README.
